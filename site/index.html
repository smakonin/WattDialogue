Residential energy research

Household energy,
explained through questions.

WattDialogue connects unsupervised load-monitoring results with questions about energy use, appliance names and comfort. The system keeps measurements, estimates and uncertain names distinct.

Try the interactive preview

Explore a readable dashboard and prepared dialogue using the same invented household examples. See how each format explains consumption, missing readings, uncertain appliance names and comfort limits.

Open study preview

Research preview with invented responses only. No participant recruitment or response collection. Answers remain in the page; submission is simulated.

Run the energy-query demo

The open-source replay demo answers energy questions using calculation tools. It runs locally with generated data. OpenAI dialogue is optional and uses keys kept on your own server.

Get the runnable demo

The browser preview uses prepared answers. Live OpenAI dialogue is available through the separately run demo.

Developed by Stephen Makonin, Simon Fraser University. The accompanying paper was submitted to IEEE PES General Meeting 2027. The engineering tests do not establish appliance-name accuracy, occupant understanding or energy savings.

The proposed utility-supplied display would let households participate without buying their own computer, smartphone or Internet subscription. This access model still needs field evaluation.
